# 瞬息 · 阅读美化制作框架

适用于瞬息 0.9.4（兼容 0.8.0 起的主题格式） 的阅读主题导入格式。本目录提供两份可独立发送给 AI 的制作说明，以及两份可直接导入的基础示例。正文只显示标题与正文，不自动显示章节编号，支持引号发言、加粗、斜体和删除线。正文与小手机主题都可使用外部字体和图片直链。

## 怎么使用

正文纸面外侧现在透明，不再额外铺白色／灰色矩形底板。主题的 background 只给纸面着色，票根外的空白与透明缺口透出瞬息日夜背景；旧票根主题不必重新导入。

0.9.4 起，正文标题也在主题作用域内：`.prose-chapter` 是包含标题和正文的一体纸面，`.prose-title` 单独控制标题外观。旧主题的边框和背景会同时包裹标题；新框架已加入标题样式，不需要另做标题卡片。

1. 根据需要打开《正文美化-发给AI.md》或《小手机美化-发给AI.md》。
2. 把开头的【风格要求】换成自己的描述，例如“古风宣纸、墨色文字、宋体、段首缩进”，或“复古短信、灰绿色屏幕、圆角方形头像”。
3. 把修改后的整份文件发给 AI。它已包含 JSON 格式、可修改组件和当前插件的实际限制，不需要另外提供源代码。
4. 将 AI 返回的完整 JSON 保存为 UTF-8 编码的 `.json` 文件。在瞬息的「美化 → 阅读美化 → 导入」中选择该文件。

AI 如有文件生成功能，可以让它直接提供 JSON 文件；如果返回的是代码块，只保存代码块里面的 JSON，不要包含围栏或说明文字。

## 正文和小手机怎么区分

插件根据文件内的 `mode` 自动分类：`prose` 进入「正文风格」，`phone` 进入「小手机风格」。文件名不影响分类，导入时也不用先切换到对应预览。

单个主题导入后会自动选中，作为之后新生成、续写章节的默认风格，并可在美化页预览。已经生成的章节保留当时的美化；它们的备份和分类导出也保留该风格。

同一个 `id` 再次导入会更新主题库中的同款美化。如果希望保留两个版本，让 AI 为新版本换一个 `id`。

删除导入主题时，先在对应的正文／小手机风格菜单选中它，再点击标题右侧的「删除」。确认框会显示主题类型和名称，确认后从主题库彻底移除并切换到内置简白，刷新后不会重新出现。内置默认风格保留；已有番外仍保留当时的样式，电脑上的原始 JSON 文件也不受影响。

0.9.4 起，小手机标题栏角色名始终居中，右侧不再有三个点；框架已说明哪些标题外观可以调整、哪些居中布局需保留。

## 本目录文件

| 文件 | 用途 |
| --- | --- |
| [正文美化-发给AI.md](正文美化-发给AI.md) | 正文主题制作提示词，可整份发给 AI |
| [小手机美化-发给AI.md](小手机美化-发给AI.md) | 手机主题制作提示词，可整份发给 AI |
| [正文美化-框架.json](正文美化-框架.json) | 可直接导入的简洁纸面示例 |
| [小手机美化-框架.json](小手机美化-框架.json) | 可直接导入的简洁灰白手机示例 |

两份 JSON 是可用的起点，不含需要手动补齐的占位字段。AI 可以在此基础上更改配色、字体、留白、圆角和各类消息卡片样式。它们只美化番外阅读区域，插件整体仍使用自己的日／夜模式。

字体可使用设备已安装的字体，也可通过 CSS 顶层 `@font-face` 的 `src: url(...)` 加载外部字体文件。背景图和头像也可使用完整 HTTP(S) URL，推荐 HTTPS。将实际链接一并提供给 AI，具体格式已写入两份框架。字体站需要允许跨域访问，断网或链接失效时使用后备字体；主题备份保存资源链接，不把远程文件自动下载打包。

## 如果提示 JSON 格式错误

请优先下载 AI 提供的原始 `.json` 文件，避免富文本复制改变引号或添加行尾反斜杠。JSON 不使用反斜杠续行；字体名称建议使用 CSS 单引号，例如 `"fontFamily": "'Songti SC', SimSun, serif"`。外层仍必须是双引号，不能把整个 JSON 改成单引号。两份新版提示词均已加入完整的输出检查规则。
