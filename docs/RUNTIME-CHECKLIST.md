# 0.9.4 实机验收

本清单用于安装到真实 SillyTavern 1.18.0 后检查。当前代码验证与本地模拟不代替下面这些结果。

- [ ] 正文阅读 iframe 无额外矩形底板／边框，票根等主题外侧透明，日夜切换后没有白底残留，纸面本身颜色不变。
- [ ] 正文标题位于主题纸面内，与正文共用边框、背景和字体；导入主题可用 `.prose-title` 修改标题，旧票根风格同样包含标题，整篇导出只显示一次标题。
- [ ] 美化页导入／导出右侧的删除按钮针对当前类型所选导入主题；取消保留、确认删除、刷新不恢复，已保存番外样式不变。
- [ ] 内置与导入小手机标题栏均无右侧三个点，角色名居中，长名字在窄屏单行省略，旧作品与分类导出一致。
- [ ] 新建番外有 HTML；续写与美化页仍只有正文／手机。HTML 请求按设置提供人物、面具、所选预设和世界书，不触发字数补写或总结。
- [ ] 跟随／独立 API 的 HTML 流式与非流式均可生成完整页面；接收过程中不执行脚本，停止或明显截断后可编辑保留代码。
- [ ] HTML 内联 CSS／JavaScript、按钮、答题、页面内弹窗、用户点击后的音频可用；内页不能访问酒馆 DOM、存储或宿主接口，外侧日夜切换不改变内页配色及运行状态。
- [ ] HTML 可编辑、复制、归类、打标签、刷新恢复；完成不显示顶部提示、作品下方无导出按钮；保存后按分类导出的 HTML 保留完整原代码，JSON 备份恢复后仍无续写或主题选择。
- [ ] 黑白票根修正版可导入，正文容器的虚线边框、背景与伪元素正常显示，PC／窄屏无横向溢出。
- [ ] 正文的引号发言、加粗、斜体和删除线均正常展示，导入主题可分别修改其样式；不恢复自动章节编号。
- [ ] 用户实际字体站提供的字体直链能在正文／手机中加载；背景图可显示，失效资源保留后备字体；HTTPS 宿主下使用 HTTPS 资源并核对字体 CORS。
- [ ] 原生扩展管理识别插件；刷新出现莫比乌斯环，无酒馆助手依赖。
- [ ] 设置显示当前角色和面具；面具弹窗修改后保存，刷新保留；「读取当前面具」恢复跟随当前酒馆面具，不改酒馆源数据。
- [ ] Chat Completion 预设下拉单选，每项右箭头才显示该项子提示词，能勾选及调整内容，查看其他项不改变预设选择。
- [ ] 世界书下拉可同时选多本，每项右箭头显示该书条目，能勾选及调整内容，酒馆源世界书未修改。
- [ ] 点击预设／世界书菜单的文字、行内空白、勾选框都能正常选择，不挂起页面；箭头只打开该项条目，菜单展开朝上、收起朝下。
- [ ] 不读取正文时生成独立番外，正文聊天条数和消息内容保持原状。
- [ ] 读取正文时只按设置选取参考，并保存在该篇快照；续写不混入新增正文。
- [ ] 跟随模式能使用当前 Chat Completion 连接；正文忙时拒绝生成番外；正文启动能取消番外。
- [ ] 独立 API 与正文同时请求，两个结果各自完整显示，主连接设置未变化。
- [ ] 收起后仍生成，完成闪动并显示未读点；停止后文本保留为未完成章节。
- [ ] 收起后的入口只有莫比乌斯环，没有方形背景／边框；日夜颜色切换、拖动可用，真实生成中光点沿环移动，结束或停止后不会一直显示忙碌动画。
- [ ] 编辑第一节后续写，AI 能使用编辑内容和本次要求，章节编号追加至同一篇。
- [ ] 续写箭头平滑旋转，折叠／展开不会重载阅读区或丢失续写要求。
- [ ] 同篇第 1 节正文、第 2 节手机、第 3 节正文，各自使用对应皮肤。
- [ ] 第 10 节生成后有 200—300 字总结；第 11 节参考该总结，第 12 节参考总结与第 11 节。第 20 节更新累计总结。
- [ ] 正文按字数、手机按 messages 内有效 type 对象判断目标；时间是消息字段，兼容旧 time 分隔。新章节显示实际／目标，旧章节无目标时仅显示实际数量；不足自动补充到当前章节，失败后可刷新并继续补足同一节。
- [ ] 生成后刷新，番外、分类、标签、阅读主题恢复；点击保存但未归类的作品在未分类中可见；未保存草稿不进入分类，不再出现草稿分类。
- [ ] 同篇放两个分类，只保留一个底层记录，删除一个分类不删除作品。
- [ ] 保存弹窗的分类下拉可搜索及多选，几十个分类时列表内部滚动；移出焦点后菜单收起。
- [ ] 小手机有双侧消息、语音转写、转账等记录展示，无法触发实际支付或通话。
- [ ] 左右头像离线可见，消息旁不显示名字；顶部是该篇快照的角色名。气泡和全部卡片不越过对方头像列。导入手机主题可修改头像圆角。
- [ ] 最大回复token 在左、流式传输勾选在右，刷新保留；输入 token 设置及旧估算限制不再生效。
- [ ] 跟随与独立连接分别测试流式勾选／取消：前者逐段返回，后者等待完整回复；供应商实际接收到 stream 和 max_tokens，正文设置保持原样。
- [ ] 非流式生成／续写／补写、剧情总结和连接测试均可完成；停止后不显示迟到回复，空回照常进入错误记录。
- [ ] 手机屏幕内滚动消息时机身、状态栏和底部横条保持固定；外侧随插件日夜底色；图片、表情包、定位、分享卡片正常。主题导出再导入按 mode 分类选中。
- [ ] 真实 API 的 429、空回或网络错误只进入设置页内带时间的报错记录，不弹窗、不在顶部常驻，刷新后保留且不显示密钥。
- [ ] 390px／320px 手机宽度下无横向溢出；分类与标签默认各一行，超出用双箭头展开换行，可组合筛选，没有自建分类时只有未分类。
- [ ] 美化与 API 菜单和预设／世界书采用相同箭头动画，圆点单选、即选即用；菜单文字及空白区可正常点击。
- [ ] 保存分类、正文／手机主题、预设和世界书的整行留白均可点击；重复点击复选项每次只切换一次，条目箭头不会额外改变选择。
- [ ] 以复古短信生成并保存后，切换手机默认风格仍保留该篇复古短信。续写可采用新的默认风格，旧节不变。
- [ ] 导入同 ID 自定义主题的新配色，旧章节仍使用原 CSS 与配色；JSON 备份恢复与分类导出也保留每节独立风格。
- [ ] 分类收藏没有重复导出按钮，从设置的数据栏可以正常按分类导出。
- [ ] ZIP 解压显示分类文件夹，单篇所有章节在同一 HTML，不展示标签。
- [ ] 完整备份恢复保留标签与分类，不带独立 API Key。
- [ ] GitHub 地址安装后，酒馆扩展管理可原位更新，资料没有丢失。

记录版本、浏览器、主 API 类型、独立接口类型和错误信息即可。不要在反馈中附 API Key。

## 1.0.2 云端更新检查

- 使用原地址、原浏览器账号更新，不清除站点数据；更新前输入的番外指令及设置仍存在。
- 酒馆扩展页可打开瞬息并隐藏／显示悬浮入口；开关后刷新仍保持。
- 正文空闲时勾选读取上下文，跟随主 API 可生成；实际正文生成时跟随模式提示等待，独立模式不读取正文时可同时生成。
- 独立 API 拉取模型并选择；真实服务商支持 /models 且回复 token 参数符合其模型限制。
- 常用宏正常展开；复杂脚本／未知宏按兼容文档的范围处理，不视为已执行；界面不显示资料兼容说明。
- 429 或其他真实 API 失败显示在生成区域，草稿仍保留；无顶部错误弹窗。
