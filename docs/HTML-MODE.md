# HTML 番外

在「番外」顶部选择 **HTML**，填写设定并生成。适用于小游戏、互动故事、信件或自定义网页。角色、面具、预设、世界书及可选正文参考仍经过现有设置和资料快照提供给 AI；原有预设条目选择、世界书触发及兼容范围不变。

## 生成与展示

- AI 被要求输出一份以 `<!doctype html>` 开始、以 `</html>` 结束的完整文档，包含 HTML、CSS、JavaScript 和移动端 viewport。使用页面内变量保存交互状态，所需交互逻辑尽量内联。
- 只在新建番外时选择 HTML；不提供续写，也不能混入正文／小手机章节。美化页仍只有正文和小手机，HTML 使用作品自己的样式。
- 使用设置里的「最大回复token」及「流式传输」。目标正文字数、消息条数、自动补写和每十节总结均不作用于 HTML。代码较长时需要足够的回复上限。
- 开启流式时展示提取出的代码文本；关闭流式时只显示等待。结束后检查文档结构，再启动网页。外部 think／thinking／cot、代码围栏、前后说明不参与完整性判断，只渲染其中的 HTML 文档；文档内脚本、样式和注释保持原样。缺少必要首尾结构或手动停止时保留已收到的代码，显示未完整状态；可以编辑补全并勾选「页面代码完整」，也可重新生成。该检查不能保证 AI 写出的所有 JavaScript 都没有错误。
- 网页在独立容器中运行。瞬息的日夜切换只改变外层，作品内的背景、字体、布局和交互由作品定义。

## 交互范围

支持页面内按钮、答题、表单输入、DOM 更新、CSS 动画、Canvas、页面内 dialog 和用户点击启动的音频等浏览器功能。允许内联 CSS、内联 JavaScript，以及 HTTP(S) 图片、字体、样式、脚本和音视频资源；外链是否可用仍取决于地址、网络和浏览器跨域／混合内容规则，字体需符合跨域要求。音频不能保证自动播放，生成提示要求提供开关并在用户操作后播放。

容器使用 `sandbox="allow-scripts"`，没有 `allow-same-origin`。作品不能读取酒馆页面、Cookie、瞬息的 IndexedDB 或会话密钥。没有向作品注入宿主 API 或密钥，也没有提供与酒馆通信的消息桥。

当前内嵌容器不支持 fetch／XHR、服务器表单提交、嵌套 iframe、eval、新窗口或顶层跳转。提示词同时要求 AI 避开这些能力。原生 alert／confirm 请改为页面内对话框。容器边界参考 [MDN iframe sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe#sandbox)。

## 保存、编辑与导出

- 「保存」沿用多分类与标签；底层仍是一篇作品，阅读代码与完整 AI 原始回复一同保存。HTML 没有阅读主题快照。
- 「编辑」展示完整 AI 回复与标题，包括外层思考、代码围栏及前后文字；保存后重新打开也保留。「复制」仅复制提取出的 HTML 文档，不加章节编号或外部文字。
- 保存并归类后，从「设置 → 数据 → 按分类导出 ZIP」导出。解压后，对应分类文件夹内的 `.html` 就是完整原代码，可用浏览器独立打开；不展示标签。作品下方不另设导出按钮。独立打开时不再经过瞬息的 iframe 容器，遵循浏览器对独立网页的规则。
- JSON 全量备份／恢复保留 HTML 类型、完整代码、分类、标签和资料快照。外链只保存地址，不自动下载外部素材。
- 保存的是**作品代码**，不是当前答题进度、运行中的变量或音频状态。切换页面、重新打开作品、刷新或保存代码后，网页会从初始状态运行；仅切换瞬息日夜模式不会重置网页。当前不提供游戏存档接口。

## 单文件预览

双击 `预览/瞬息-1.0.13-单文件预览.html`，选择 HTML，填写任意设定并点击生成。预览固定输出离线示例《痴鬼念》：五道题、连错三次后的循环、重置按钮和合成音效开关。音效由浏览器合成，无需下载音乐；示例仅用于检验展示与操作，不消耗 API，也不会按输入现场创作新游戏。

正式插件通过已配置的 API 生成作品。最终作品的逻辑与美术效果取决于模型输出；插件不保证任意生成代码都符合用户的创作要求。

## 1.0.13 预设隐藏规则

新 HTML 会保存所选预设中替换为空（或只有空白）的规则。阅读、复制与分类导出使用过滤后的文档，原始回复仍在编辑、备份和同步中。正文美化替换、角色正则不自动用于 HTML。文档中的 script、style、template、textarea、title、注释和属性不做文字过滤，避免破坏页面代码。

清除确因匹配内容移除而变空的普通 div／aside／footer／section／p／span。带 id、事件、交互属性或被页面脚本引用的容器保留；不会泛删全部空元素。对用户手动挪走防截断文字后留下的 body 之外空 div.marker 也做清理。

旧作品没有规则快照时，打开编辑后保存一次，会读取该作品原预设名下当前选择的隐藏规则；原预设不可读取时报告错误，编辑草稿保留。没有原预设名称的旧作品不套用当前其他预设。
